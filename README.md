# สวนจับผลไม้ 🍎

เกมเว็บแคมสั้น ๆ ที่ใช้การตรวจจับ**มือ** (ไม่ใช่การเคลื่อนไหวทั่วไป) ควบคุมตะกร้ารับผลไม้ ผ่านโมเดล MediaPipe Hand Landmarker รองรับทั้งโหมด **1 คน** และ **2 คน** (ยืนคู่กันหน้ากล้อง คนละฝั่งจอ คุมตะกร้าคนละสี — แต่ละฝั่งล็อกอยู่ในโซนตัวเองเพื่อไม่ให้แย่งตะกร้ากัน) มี **ระเบิด 💣** ปนมากับผลไม้ จับโดนแล้วเสียแต้ม พร้อม**เสียงเอฟเฟกต์** (จับผลไม้ ระเบิด นับถอยหลัง เริ่ม/จบเกม) ที่สังเคราะห์สดด้วย Web Audio API ไม่ต้องโหลดไฟล์เสียงเพิ่ม และมี**แถบสถิติ**ท้ายเกมสรุปจำนวนผลไม้ที่จับได้ ระเบิดที่โดน และความแม่นยำของแต่ละคน

```
fruit-catch-game/

```

## วิธีรันใน VSCode
กล้อง (`getUserMedia`) และการโหลดโมเดล ES module ต้องรันผ่าน `http://localhost` หรือ `https://` เท่านั้น เปิดไฟล์ตรง ๆ แบบ `file://` จะใช้งานไม่ได้

ต้องมีอินเทอร์เน็ตตอนเปิดเกมครั้งแรก เพราะ `script.js` โหลดไลบรารี MediaPipe (`@mediapipe/tasks-vision`) และไฟล์โมเดลตรวจจับมือจาก CDN โดยตรง

แนะนำให้ใช้ extension **Live Server**:
1. ติดตั้ง extension "Live Server" (โดย Ritwick Dey) ใน VSCode
2. คลิกขวาที่ `index.html` → เลือก **Open with Live Server**
3. เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:5500/...` โดยอัตโนมัติ

หรือถ้าไม่ใช้ extension จะรันด้วยคำสั่งในเทอร์มินัลก็ได้ เช่น:
```bash
npx serve .
# หรือ
python -m http.server 8000
```
แล้วเปิด `http://localhost:8000` ในเบราว์เซอร์

## เชื่อมกับ OBS
- **สตรีมเกมออก:** เพิ่ม Source แบบ `Window Capture` (เลือกหน้าต่างเบราว์เซอร์ที่เปิดเกม) หรือ `Browser Source` ชี้ไปที่ URL ของ Live Server
- **ให้ภาพกล้องผ่านฟิลเตอร์ OBS ก่อนเข้าเกม:** เปิด OBS → ใส่กล้องจริงพร้อมฟิลเตอร์ → กด "เริ่ม Virtual Camera" → กลับมาที่เกมแล้วเลือกกล้องชื่อ `OBS Virtual Camera` ตอนเบราว์เซอร์ขอสิทธิ์
